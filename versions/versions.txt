# The Minecraft releases kine supports: the one place to add a version (see versions/README.md).
#
# minecraft: the release. epoch: the folder under versions/ holding the code for the game APIs that differ (several
# releases share one when kine's game code is the same on them). loader and fabric_api: the oldest Fabric Loader and
# Fabric API tested with it; the jar requires at least these. java: the Java release the game runs on. family: the
# releases one jar covers (an unobfuscated 26.x jar and an obfuscated 1.21.x jar can't be one jar).
#
# The development version (runClient, where new features are written first) is gradle.properties' dev_version, any
# release of the newest family. A row starting with "pending" is a release still being ported, left out of the build
# unless it is run with -Pkine.pending=true.
